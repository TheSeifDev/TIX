# Animation parity report

The first native increment registers GSAP and ScrollTrigger once, uses `useGSAP()` with `revertOnUpdate`, honors `prefers-reduced-motion`, and scopes reveal/hero effects to the current page. Existing CSS animation rules remain available. Full parity for the WorkLens, Disrupt pin, portfolio overlay, and services motion systems is not yet marked complete because dedicated browser interaction assertions are still required.
